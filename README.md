# Vehicle Service Booking System

A console-based Java application for managing vehicle service bookings using JDBC and MySQL.

## Features
- Add booking
- View bookings
- Update booking
- Delete booking
- Search by vehicle number

## Technologies Used
- Java
- JDBC
- MySQL

## How to Run
1. Create the database using the SQL script
2. Add MySQL JDBC connector
3. Compile Java files
4. Run Main.java
